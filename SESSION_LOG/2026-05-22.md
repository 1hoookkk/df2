# Session 2026-05-22 — Forge upload-to-corner extraction loop

## Goal

Replace the current standalone Forge app surface with the transient-fit
corner assignment loop Tyson described: upload, inspect response and
residual, assign A/B/C/D.

## Code

- Reworked `forge/src/main.rs` into an `eframe::App` with raw `f64`
  audio state, detected onset, live fit-window state, fitted corner
  result state, A/B/C/D corner slots, and a read-only C++ DF2T output
  terminal.
- Upload auto-detects the onset and fits the first 100 ms body window.
  The exposed user controls are fit window position and 50–200 ms length;
  the waveform still has draggable start/end markers for the same window.
- Wired fitting to `trench_core::lpc::fit_corner`, then reflects unstable
  pole radii, clamps radii to `[0.5, 0.9985]`, sorts stages by pole
  frequency, and re-normalizes peak gain through the existing core helper.
- Added a synth-back residual from the fitted kernel impulse response.
  `≤ -24 dB` is ready, `>-24 dB` is yellow/review and still assignable,
  and `>-8 dB` or non-finite results are red/blocked.
- Added fitted response and six pole/zero actor plots plus corner
  state plots.
- Reweighted authoring to the two-anchor loop: `LOW A` and `HIGH B`
  assignment are primary, the response plot overlays A/B plus the
  current packed A→B preview, and the Morph Path panel drives the
  existing Forge noise audition engine.
- C/D assignment moved under Advanced as optional hidden-axis corners.
  The primary preview duplicates A/B across the hidden axis while
  preserving the four-corner runtime/body shape.
- Corrected the public UI after Tyson rejected the extraction-console
  surface. Forge now opens as a minimal high-end product surface:
  `LOW SOUND`, `HIGH SOUND`, a large living Shape canvas, one Morph rail,
  `Play`, `Save`, and `Reset`.
- Technical fit details are no longer in the product view. Failed/messy
  inputs expose a simple slice picker; the waveform bench, residual,
  response/z-plane plots, DF2T terminal, conditioning controls, and
  hidden corners are behind `Inspect`.
- `Save` now writes the two-anchor body to
  `~/Documents/TRENCH/authoring_slot.json`, duplicating A/B over the
  hidden axis unless advanced C/D corners are authored.
- Capture conditioning controls moved under Advanced: Hann windowing is
  automatic; 16-bit zero-dither truncation and internal rate stay
  available there.
- WAV loading uses the existing `hound` dependency and the load button
  uses `rfd`.
- Added `egui_plot` and `rfd` to `forge/Cargo.toml`.
