## ROM corner words captured — packed parity RESOLVED

- Captured skin-13 ROM corner words via Cheat Engine runtime dump
  (Emulator X3 VST hosted in FL Studio, 44100 Hz). Object base located by
  anchoring on the decoded-coefficient grid at +0x540.
- First 240-byte dump at the assumed object+0x2C0 was wrong (zeros);
  re-dumped the full 73728-byte allocation region instead.
- `tools/locate_corners_in_dump.py` found the corner block at object+0x2C0
  (dump offset 0x870) — but no u16 block decoded cleanly: c0-c3 matched the
  M0_Q0 grid exactly, **c4 was off by exactly 4x**.
- **Root cause: c4 recombination bug.** Engine uses `c4 = 4*d4`; df2's
  packed model used `c4 = d4`. The 4.0 scale is the constant
  `FUN_1802c0150` writes to `this+0x2a8`. Derived-packed hid it (encode/
  decode round-trip) — but it encodes `w4 = encode(c4)` vs the engine's
  `encode(c4/4)`, so the c4 word interpolates in the wrong minifloat octave.
- `tools/rom_corner_audit.py` (corrected `c4 = 4*d4` decode):
  - all 4 ROM corners decode to the P2K JSON grids within 2-3e-6 → the
    `P2k_013` JSON corner coefficients were always accurate.
  - M50/Q50 clean-window null vs X3 wet: **-95.41 dB** = bit-accurate, PASS.
- Correction (caught on re-run): the c4 fix is a **no-op for the
  derived-packed path** — `c4` vs `c4/4` is a uniform minifloat exponent
  shift, the integer lerp passes it through, the ×4 decode undoes it. The
  c4 bug mattered only for *reading real ROM words* (old decode read ROM
  `w4` 4× small → garbage −0.00 dB). The −53.75 dB derived gap is JSON
  6-decimal-place truncation of w0-w3 (22-422 LSB vs ROM) — the original
  `packed_gap_diagnosis` "decimal-truncated floats" hypothesis was right.
- Captured data (reference-only): `dev/tmp/cheat_engine_dump/
  skin13_region_full.bin`, `skin13_corners_rom.bin`.
- Code fix applied: `c4 = 4*d4` / `w4 = encode(c4/4)` in
  `pyruntime/packed_interp.py`, `tools/coefficient_field_bakeoff.py`,
  `trench-core/src/minifloat.rs`. Rust tests green (38 lib + 7 packed_interp
  integration). Packed path stays non-default, cartridge format unchanged.
