## Session 2026-05-21 (later) — built the TRENCH Forge (standalone Rust .exe)

Architecture relocked to **Pure Rust** (see STATE + memory): the Forge is a
standalone `.exe` (eframe/egui), linking `trench-core` directly — no Wasm, no
HTML, no JUCE for the authoring tool. nih-plug reserved for the shipping
player only. Built and shipped this session:

**New crates/files**
- `forge/` — eframe/egui app (workspace member). `forge/src/main.rs` +
  `forge/src/audio.rs`.
- `trench-core/src/lpc.rs` — pure-Rust capture fitter (no new deps).
- `tools/make_test_sounds.py` — synth vowels + metal tube for testing.
- `trench-core/tests/forge_cartridge_roundtrip.rs` — e2e data-path test.

**Fitter (`lpc.rs`)** — port of `tools/lpc_extract.py` + zeros:
- Levinson-Durbin LPC + Durand-Kerner rooting → resonant poles.
- Zeros from spectral valleys (anti-resonances) → real pole-zero biquads
  (the Hedz "notches", not just peaks). All-pole was only half the picture.
- Analysis widened to 22.05 kHz / order 14 / band ≤10 kHz so bright material
  can populate the air/RIP actor.
- `fit_corner` re-homes poles at the runtime rate; per-corner peak
  normalization (`normalize_corner_peak`, now pub). Tests pass (recovers
  planted formants; finite/stable corners).

**Forge app**
- Sound-space surface ONLY — no z-plane, no "EMU", no DSP vocab (see
  [[never-show-dsp-on-surface]]). Hero = THE SHAPE (filter response) with the
  six named actors riding on it; live audio rendered as a crude, **aliased**
  stepped reactor trace (feathering off).
- Drop a `.wav` → Welch envelope shown green → FIT into one of **four
  independent corners** (drop any sound on any corner; engine guarantees a
  stable morph between any four — Rossum's bounded-u16 interpolation).
- **DEPTH** dial (push poles+zeros toward the circle: gentle→Ear-Bender
  rails) and **WILD** dial (reorder morph-end stages → cross-spectrum
  migration = the Ear-Bender tear).
- M/Q pad filled with **morph terrain** (each point colored by spectral
  centroid/energy) — explorable, not an empty void.
- **Audio**: cpal output, multi-format (f32/i16/u16/i32), runs the cascade at
  39062.5 via linear resampling, coefficients RAMPED (click-free morph).
  Source toggle: **NOISE** (pink) or **SAMPLE** — the dropped sound looped
  through the morph, so you hear YOUR material (drum loop / vocal) talk.
  (NEEDS Tyson's ear-check — built/streams without error but not audibly
