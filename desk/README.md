# THE DESK

This folder is yours. It is the only place in this repo you ever need to open.
Everything outside it is Claude's machine room — wiring behind the wall.

## How it works

1. **Open `SHEETS.md`** → it links to the current judgment sheets. Big curves,
   dB vs frequency. The plot tells everything; the audio under each plot is
   confirmation if you want it.
2. **Judge.** Tell Claude keeps and kills by wave + number ("wave2 #9 keep,
   wave1 #3 kill — no low end under Q"). Your words matter as much as the verdict.
3. **Keeps land in `bank/`** with your words attached, audited through the real
   engine, and get wired into the plugin. `bank/` IS the product.
4. **Kills land in `KILLS.md`.** A good kill note ("too polite") steers the
   machine better than any setting.

You never touch git, configs, or code. If something here looks wrong, say so —
that's a bug report, not your problem to fix.

## What's here

- `SHEETS.md` — links to the judgment sheets for the current candidate waves
- `sheets/` — the sheets themselves (plots + audio, self-contained)
- `bank/v1/` — the kept bodies + `BANK.md`, the keeper ledger
- `KILLS.md` — the kill ledger
