# Bat Phaser / CPhantomBatman ROM extraction

Batman is not a P2K minifloat bank and must not be loaded through
`ref/presets/*.bin`.

It is a dedicated fixed-point ROM path:

- vtable: `0x1806d6030`
- loaders: `FUN_1802c5620`, `FUN_1802c5710`, `FUN_1802c57F0`, `FUN_1802c58D0`
- ROM bases: `0x1806d6CC0`, `0x1806d6E00`, `0x1806d6FE0`, `0x1806d71C0`
- fixed LP2Pole ROM base: `0x1806d65E0`

Generated by:

```text
python tools/extract_emulatorx_rom_filters.py
```

Primary artifact:

- `batman_rom.json` — decoded coefficients for all Batman loaders and the
  fixed LP2Pole stage.

Raw sidecar files preserve the exact ROM bytes for each loader.
