QCREATOR  APPLICATION EXAMPLES

Instructions:

Launch Qcreator(TM) 
Select "Open" in the "File" menu.
Demo files are located in the "Sndfiles" folder.
Filenames are: "Demo1.wav" & "Demo2.wav"
Select the desired demo file you wish to open.

**Note** These two demo files have been preprocessed with Qcreator(TM). 
They already contain application-specific information to allows the program 
to cxeate 3D effects with these mono files. If you try to open these files 
directly by double clicking on the demo files themselves, they will be opened 
by the computer's default wav playing device (typically an application such 
as Media Player) and the resulting output will only be mono.

Demo1.wav
=========

This example shows you  how you can use QCreator(TM) to create dynamic motion 
through constant panning. The pan line represents the position of the helicopter 
relative to the listening position. You can also see this relationship in the 
key diagram at the bottom right of the interface. As the file is played, the 
yellow sound icon moves through the pan positions and shows you where the 
helicopter is placed relative to you.


Demo2.wav
=========

This fun example was developed to show how QCreator (TM) can also provide the 
ability to statically place elements at any point along the entire pan position 
and keep them there. The pan line here represents the standard pan positions 
in the application; center, stereo left, stereo right, QSound Left and QSound Right.
